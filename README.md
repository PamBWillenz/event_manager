# Event Manager

## Overview

A program that manages event information and attendees. This application helps organize and track event registrations, attendance, and related data.

## Features

- Load and parse attendee data
- Generate personalized communications
- Track registration dates
- Analyze attendance statistics

## Installation

```bash
git clone https://github.com/yourusername/event_manager.git
cd event_manager
```

## Usage

```ruby
ruby lib/event_manager.rb
```

## Dependencies

- Ruby (version 3.3.0)
- Required gems listed in Gemfile
